# Independent provider boundary

The academy does not import Workshop provider configuration or its management commands. Read lesson 85 in the academy for the complete injected-transport example, normal and malformed decisions, and classified failure boundaries. `model_adapter.py` is a standalone validator/adapter. The transport you supply owns authentication, request timeouts, classified retries and reported usage; the agent harness retains tool authority. The included fake request is an offline fixture and makes no model call.
