## Understand the decision: Grounding, citations, and abstention

## Before you begin

## Why this decision matters

Grounding means constraining answers to available evidence and checking that claims are supported. A citation is useful only when the reader can locate the exact passage and verify the conclusion. Attaching a source URL after generation is not grounding. An unsupported answer must not become acceptable merely because it sounds reasonable.

Define three responses: answer when evidence supports the claim, clarify when a missing input changes applicability, and abstain when sources do not establish the answer. Do not convert similarity scores into calibrated confidence percentages. Observe abstention quality alongside answer quality so a system cannot appear accurate by refusing everything.

## Vocabulary used in this session

### Grounded answer

A draft whose factual claims are supported by the evidence available for that run.

### Clarification

A request for missing user information that changes how a rule applies.

### Abstention

An explicit inability to establish an answer from the available sources.

## Learn each concept step by step

Work through these explanations before the completed example or exercise. Follow the inputs, mechanism and decision boundary rather than memorizing the definitions.

## Step 1 · Grounded answer

A grounded answer needs applicable evidence for every factual claim, not merely a real citation. The fixture uses manually reviewed support labels to demonstrate the decision boundary. Keep eligibility conditions and exceptions intact. Model fluency, citation count and valid JSON are separate from whether the claim follows from the policy.

## Step 2 · Clarification

Clarification asks for missing user information that changes applicability. If a return policy exists but item condition is unknown, ask whether the item is unopened. Avoid asking irrelevant questions just to postpone answering. Record which missing field prevented the decision so reviewers can distinguish useful clarification from unnecessary refusal.

## Step 3 · Abstention

Abstention means the available authorized sources cannot establish an answer. An enterprise customer may require a different policy from a retail customer even when both documents exist. Select scope before generation. A known negative policy answer is still an answer; lack of evidence, rather than an unfavorable outcome, is what justifies abstention.

## Predict before running

Use Python 3.12; every import and synthetic fixture required for this example is included. Run `python3 -I example.py`. Assertions must be enabled; do not use `-O`.
```python
def decide(condition, source, claim):
    if source is None:
        return 'abstain'
    if condition is None:
        return 'clarify'
    # A human-prepared fixture label, not automated semantic entailment.
    support_labels = {('unopened','Unopened within 14 days'):True,
                      ('opened','Opened items qualify'):False,
                      ('opened','Opened items are excluded'):True}
    return 'draft_for_review' if support_labels.get((condition,claim),False) else 'revise_or_abstain'
policy = 'Only unopened items within 14 days; opened items excluded.'
assert decide(None, policy, '') == 'clarify'
assert decide('unopened', None, '') == 'abstain'
assert decide('opened', policy, 'Opened items qualify') == 'revise_or_abstain'
assert decide('opened', policy, 'Opened items are excluded') == 'draft_for_review'
assert decide('unopened', policy, 'Unopened within 14 days') == 'draft_for_review'
print('missing applicability: clarify; missing source: abstain; contradicted claim: revise')
```

## Walk through the mechanism and its limits

The order matters: no policy means unavailable evidence; a known policy with missing item condition needs clarification. The support table is explicitly manually labeled. It teaches expected behavior without pretending string membership can solve entailment. A live model must be evaluated on claim support, exception preservation, and applicability independently of citation ID checks.
