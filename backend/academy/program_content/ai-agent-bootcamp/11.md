## Why this decision matters

An agent loop observes a state, chooses an allowed next action, invokes a tool, and incorporates the result. Without explicit stopping conditions, it can repeat the same ineffective action indefinitely. Model state as application data rather than an accumulating string of conversation.

Use states such as needs_context, drafting, needs_review, done, and failed. Record the tool result and transition that occurred, not an imagined successful action. Enforce maximum steps, overall time, and budget outside the model. Compare the loop with a fixed retrieve-then-draft workflow; agency must justify its added complexity through measurable gains.

## Vocabulary used in this session

### Agent state

Structured application data recording observed results and the current stage.

### Transition

An explicitly permitted movement between states.

### Step limit

An application-enforced maximum number of iterations independent of model instructions.

```python
def run(decisions, max_steps=3):
    trace = []
    for action in decisions:
        if len(trace) >= max_steps:
            return {'status':'step_limit','trace':trace}
        if action not in {'retrieve','answer','abstain'}:
            return {'status':'failed','trace':trace + ['rejected:'+action]}
        trace.append(action)
        if action in {'answer','abstain'}:
            return {'status':action,'trace':trace}
    return {'status':'needs_context','trace':trace}
assert run(['retrieve']*3 + ['answer'])['status'] == 'step_limit'
assert run(['retrieve','answer'])['trace'] == ['retrieve','answer']
assert run(['retrieve','delete'])['status'] == 'failed'
assert run([])['status'] == 'needs_context'
print('terminal states: answer, abstain, step_limit, failed; no fabricated success')
```

## Walk through the mechanism and its limits

The decision list replaces a model so control flow can be inspected deterministically. The runtime checks the step budget before executing another proposal. Only an allowed terminal action ends successfully. This example bounds steps but not time, tokens, or tool exceptions; those must be added explicitly rather than inferred from a finite loop.

## Worked example

A fixed workflow retrieves once and drafts. A bounded alternative allows one query reformulation if no relevant evidence is found, then abstains. It has at most two retrieval calls and one draft. A fake provider that repeatedly requests retrieval cannot bypass the application’s counter.
