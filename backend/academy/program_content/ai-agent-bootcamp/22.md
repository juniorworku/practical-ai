A vertical slice connects a real user action through UI, API, retrieval, draft generation, persistence, and visible result. It is more valuable than six disconnected components that each work alone. ## Predict before running

Read the assertions and predict the output and rejected cases. Save the **entire** following block as `example.py` in a new scratch folder. Use Python 3.12; every import and synthetic fixture required for this example is included. Run `python3 -I example.py`. Assertions must be enabled; do not use `-O`. No model, network, database service or third-party package is required. SQLite examples create a temporary database and clean it up.

```python
import sqlite3
from tempfile import TemporaryDirectory
from pathlib import Path
POLICY = {'id':'returns-v1','text':'Unopened items within 14 days.'}
def draft(condition, provider):
    if condition is None: return {'status':'clarify','citations':[]}
    if condition!='unopened': return {'status':'abstain','citations':[]}
    try: answer = provider(POLICY['text'])
    except TimeoutError: return {'status':'generation_failed','citations':[]}
    return {'status':'needs_review','answer':answer,'citations':[POLICY['id']]}
def offline(text): return text  # Deterministic fake provider, not a trained model.
with TemporaryDirectory() as folder:
    path=Path(folder)/'runs.sqlite'
    db=sqlite3.connect(path)
    db.execute('CREATE TABLE runs(id TEXT,owner TEXT,status TEXT,source TEXT)')
    result=draft('unopened',offline)
    with db: db.execute('INSERT INTO runs VALUES(?,?,?,?)',('r1','acme',result['status'],result['citations'][0]))
    db.close(); db=sqlite3.connect(path)
    assert db.execute('SELECT source FROM runs WHERE id=? AND owner=?',('r1','acme')).fetchone()==('returns-v1',)
    assert db.execute('SELECT source FROM runs WHERE id=? AND owner=?',('r1','other')).fetchone() is None
    assert draft(None,offline)['status']=='clarify'
    assert draft('opened',offline)['status']=='abstain'
    def unavailable(text): raise TimeoutError()
    assert draft('unopened',unavailable)['status']=='generation_failed'
    db.close()
print('offline application slice: draft, clarify, abstain, failure, durable scoped readback')
```

## Walk through the mechanism and its limits

This deliberately small application-layer slice connects policy selection, fake drafting, an explicit status, a source revision and durable owner-scoped readback. It is not a UI/API capstone by itself. The hard-coded condition supports only this synthetic policy, not free-text eligibility reasoning. It gives you a known baseline to connect to your own actual browser and DRF endpoint.

## Extend the example
