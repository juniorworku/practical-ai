## Vocabulary used in this session

### PCM contract

Sample rate, channels, signed width and byte order of raw audio.

### Backpressure

An explicit response to producers outpacing consumers.

### Bounded queue

A finite buffer whose capacity has a measured latency/memory meaning.

## Learn each concept step by step

Read these three explanations before running the specimen. Each connects a definition to the decision it controls.

## Step 1 · PCM contract

For mono PCM16 at 16,000 samples/second, each second is 16,000×2=32,000 bytes. A 320-byte frame is 10ms. Channels multiply this byte rate. Browser WebM/Opus is compressed container data and cannot be sent as if it were these raw samples; encoding and playback rate must be agreed at each boundary.

## Step 2 · Backpressure

Backpressure lets the consumer limit the producer. await queue.put(frame) pauses when the finite queue is full, whereas put_nowait raises QueueFull immediately. Pausing is appropriate only if the upstream can wait; a physical microphone continues capturing, so its capture/drop/stop behavior must also be explicit. Buffering forever only converts overload into growing latency.

## Step 3 · Bounded queue

Queue capacity has a time meaning. Two 10ms frames hold 20ms of queued audio, excluding frames being captured, transmitted or played. Add those other stages to end-to-end latency. A queue bound limits memory; it does not establish accurate speech or prompt response. Disconnect must terminate producer and consumer rather than leave them waiting on one another.

## Read, run and explain the complete implementation

## Walk through the data and state

1. The fast baseline producer accepts sequences 0 and 1 into a two-item queue.

2. Sequences 2–4 overflow visibly; accepted=2 and dropped=3.

3. The frame-duration assertion uses 320 bytes at 32,000 bytes/second to obtain 10ms.

## Predict before execution

Save this entire block as example.py in an empty directory. Run `python3 -I example.py` with assertions enabled. It uses only the Python standard library, includes its synthetic data and performs no provider calls. Explain each assertion before running.

```python
import asyncio
async def main():
    queue=asyncio.Queue(maxsize=2)
    accepted=dropped=0
    for sequence in range(5):
        frame={'sequence':sequence,'pcm':b'\x00\x00'*160}
        try: queue.put_nowait(frame); accepted+=1
        except asyncio.QueueFull: dropped+=1
    frames=[]
    while not queue.empty():
        item=await queue.get();frames.append(item['sequence']);queue.task_done()
    assert frames==[0,1] and dropped==3
    # At 16kHz mono PCM16, 320 bytes represents 10 milliseconds.
    assert (320/(16000*2))*1000==10
    print({'accepted':accepted,'overload':dropped,'frame_ms':10})
asyncio.run(main())
```
