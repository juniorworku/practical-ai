## Module 2 · Data Grounding & Advanced RAG · system design

Treat retrieval as a data product with explicit lifecycle states: received, parsed, chunked, embedded, indexed, evaluated and active. Upload success is not search readiness. A failed replacement revision must not remove the last working active index. Preserve original digest, owner, source revision and page/paragraph/timestamp locators before normalization.

PDF extraction can fail on scans; DOCX can contain tables or large decompressed archives; websites can redirect to unintended hosts; transcripts need time anchors and permissioned provenance. The complete parser handles text PDFs, DOCX paragraphs/tables, approved-origin HTML and supplied VTT transcripts. It deliberately rejects an unreadable scan rather than claiming OCR. Run CPU/untrusted parsers in bounded workers with page/byte/time limits instead of blocking an async request loop.

Chunking is an engineering trade-off. Fixed token windows are reproducible; heading/semantic boundaries can preserve meaning but add cost or variability. Compare retrieval and answer support on the same cases. Keep exceptions and applicability conditions attached, budget metadata and output reserve, and record offsets so a reviewer can inspect the original evidence.

Embedding model/version/dimension and normalization form an index contract. A model migration requires a parallel index and a measured promotion decision, not mixing vectors. Start with exact tenant-filtered search. Approximate indexes can trade recall for latency and may return too few authorized results after filtering. Use actual execution plans and relevance labels when tuning HNSW rather than memorizing a parameter.

Hybrid retrieval combines complementary candidate lists. Reciprocal-rank fusion avoids assuming lexical and vector scores share a scale. A reranker can reorder a bounded candidate set but cannot recover absent evidence. Its extra latency and spend must fit the remaining deadline and demonstrate useful quality gain. Citation membership proves identity; factual support and correct policy applicability require separate review. Stream draft text with explicit complete/error events, and never cache a partial answer as final. A source-grounded chat capstone earns its claim through owner isolation, provenance, no-answer behavior, revision activation, evaluation and recovery—not by resembling a chat interface.

## Mixed-media intake, parsing and provenance · concepts and decision

## The case

An uploaded PDF is a scan while a DOCX includes tables and a VTT transcript carries timestamps.

## Reason through the decision

Quarantine the unreadable scan; retain table and time provenance for usable sources without claiming OCR/transcription.

Intake records an immutable content digest and owner before parsing. Same bytes under another tenant are not permission to reuse private output. A filename extension is only an initial allowlist, not trusted content detection. Worker limits must include decompressed DOCX size, PDF page count and parser time; a small upload can still trigger excessive work. Activation and upload receipt remain separate states.

## Vocabulary used in this session

### Content digest

Identity of exact input bytes, not proof of their trustworthiness.

### Parse quarantine

A visible failed/unreadable state excluded from active retrieval.

### Locator

Page, paragraph or timestamp connecting extracted content to its source.

## Learn each concept step by step

Read these three explanations before running the specimen. Each connects a definition to the decision it controls.

## Step 1 · Content digest

A digest identifies exact bytes: changing one byte changes the content identity. It does not prove authorship, permission or safety. Use (owner,digest) for intake deduplication so identical bytes submitted by different organizations do not become a cross-owner access shortcut. Keep original bytes or a recoverable source reference for audit.

## Step 2 · Parse quarantine

Parsing is a lifecycle transition, not an upload acknowledgement. received means bytes were accepted; parsed means extraction succeeded; active means all later chunk/index/evaluation gates passed. A scanned PDF may contain no extractable text, so quarantine it with a visible reason. Keep the last active revision while a replacement is being processed.

## Step 3 · Locator

A locator lets someone inspect evidence at its origin. A PDF page number, DOCX paragraph/table ID and VTT time range serve different source formats. Store the locator with the digest/revision before cleaning text. Without it, a generated citation may look plausible while the student or reviewer cannot find the actual evidence.

import hashlib
jobs={}
def ingest(owner,filename,raw):
    if len(raw)>1000: return 'rejected_size'
    suffix=filename.rsplit('.',1)[-1].lower()
    if suffix not in {'txt','pdf','docx','vtt'}: return 'unsupported'
    key=(owner,hashlib.sha256(raw).hexdigest())
    jobs.setdefault(key,{'state':'received','filename':filename,'bytes':len(raw)})
    return key
key=ingest('acme','note.txt',b'Approved policy')
assert ingest('acme','note.txt',b'Approved policy')==key
assert ingest('other','note.txt',b'Approved policy')!=key
assert ingest('acme','huge.pdf',b'x'*1001)=='rejected_size'
print({'jobs':len(jobs),'duplicate_same_owner':'deduplicated','oversize':'rejected'})

```python
"""Mixed-media intake with stable provenance. No OCR or remote transcription.
python media_ingest.py approved.txt transcript.vtt document.pdf handout.docx
Install pypdf/python-docx/httpx from live_requirements.txt in an isolated env.
"""
import argparse
import hashlib
import json
from pathlib import Path
import re
from urllib.parse import urlsplit
import zipfile

def parse_document(path):
    path=Path(path)
    if path.stat().st_size>10_000_000:raise ValueError('upload exceeds 10 MB teaching limit')
    raw=path.read_bytes()
    if len(raw)>10_000_000:raise ValueError('upload exceeds 10 MB teaching limit')
    digest=hashlib.sha256(raw).hexdigest();suffix=path.suffix.lower();sections=[]
    if suffix=='.pdf':
        from pypdf import PdfReader
        reader=PdfReader(path)
        if len(reader.pages)>100:raise ValueError('page budget exceeded')
        for number,page in enumerate(reader.pages,1):
            text=(page.extract_text() or '').strip()
            if not text:raise ValueError('empty/scanned page requires a separate OCR review path')
            sections.append({'locator':f'page:{number}','text':text})
    elif suffix=='.docx':
        with zipfile.ZipFile(path) as archive:
            if sum(i.file_size for i in archive.infolist())>30_000_000:raise ValueError('expanded archive budget exceeded')
        from docx import Document
        document=Document(path)
        for number,p in enumerate(document.paragraphs,1):
            if p.text.strip():sections.append({'locator':f'paragraph:{number}','text':p.text.strip()})
        for number,table in enumerate(document.tables,1):
            sections.append({'locator':f'table:{number}','text':'\n'.join(' | '.join(c.text for c in row.cells) for row in table.rows)})
    elif suffix=='.vtt':
        text=raw.decode('utf-8-sig')
        for block in re.split(r'\n\s*\n',text):
            lines=block.splitlines();timing=next((i for i,l in enumerate(lines) if '-->' in l),None)
            if timing is not None:sections.append({'locator':'time:'+lines[timing].strip(),'text':' '.join(lines[timing+1:]).strip()})
    elif suffix in {'.txt','.md'}:
        sections=[{'locator':'text:1','text':raw.decode('utf-8').strip()}]
    else:raise ValueError('unsupported input format')
    if not sections or any(not s['text'] for s in sections):raise ValueError('no usable text; quarantine instead of activate')
    return [{'document':path.name,'digest':digest,**section} for section in sections]

async def fetch_approved(url,allowed_origins):
    """allowed_origins is server/operator configuration, never a model field.
    Production still needs DNS/IP egress enforcement and parser worker limits.
    """
    import httpx
    parsed=urlsplit(url);origin=f'{parsed.scheme}://{parsed.netloc}'
    if parsed.username or parsed.password or parsed.scheme not in {'http','https'} or origin not in allowed_origins:
        raise ValueError('URL origin not approved')
    chunks=[];size=0
    async with httpx.AsyncClient(follow_redirects=False,timeout=10) as client:
        async with client.stream('GET',url) as response:
            response.raise_for_status()
            if response.is_redirect:raise ValueError('redirects require a new origin decision')
            async for data in response.aiter_bytes():
                size+=len(data)
                if size>1_000_000:raise ValueError('website byte budget exceeded')
                chunks.append(data)
    from html.parser import HTMLParser
    class Text(HTMLParser):
        def __init__(self):super().__init__();self.parts=[];self.skip=0
        def handle_starttag(self,tag,attrs):
            if tag in {'script','style'}:self.skip+=1
        def handle_endtag(self,tag):
            if tag in {'script','style'}:self.skip=max(0,self.skip-1)
        def handle_data(self,data):
            if not self.skip and data.strip():self.parts.append(data.strip())
    raw=b''.join(chunks);parser=Text();parser.feed(raw.decode('utf-8',errors='replace'))
    text=' '.join(parser.parts)
    if not text:raise ValueError('no readable website text')
    return {'document':url,'digest':hashlib.sha256(raw).hexdigest(),'locator':'html:text','text':text}

if __name__=='__main__':
    args=argparse.ArgumentParser();args.add_argument('paths',nargs='+');parsed=args.parse_args()
    for path in parsed.paths:
        for row in parse_document(path):print(json.dumps(row,ensure_ascii=False))
```
