## The case

A replacement embedding model returns the same vector length as the previous one.

## Reason through the decision

Do not mix spaces; build, evaluate and activate a separately versioned index.

Vectors from different embedding models are not interchangeable even if their lengths happen to match. Store model/version, dimension and normalization policy with the index manifest. Re-embedding should build a new searchable revision, evaluate it and switch an active pointer; silently mixing vectors can produce plausible but meaningless nearest neighbors. The fixture does not simulate semantic embedding quality.

## Vocabulary used in this session

### Embedding space

A model/version/dimension-specific representation contract.

### Parallel index

A new revision evaluated without overwriting the active search state.

### Activation gate

A checked decision to switch current queries to a ready revision.

## Learn each concept step by step

Read these three explanations before running the specimen. Each connects a definition to the decision it controls.

## Step 1 · Embedding space

An embedding API maps text to coordinates in a particular learned space. Distance is meaningful only within a compatible model/version, dimension and normalization policy. Two models can both return three numbers with unrelated meanings. Reject incompatible records before insertion rather than padding vectors or mixing them behind a shared model name.

## Step 2 · Parallel index

Build a parallel index for a migration: leave v1 searchable, ingest the same approved corpus through the replacement model into v2, evaluate v2 on held-out labels, then switch an active pointer. This costs temporary storage and ingestion work but makes rollback possible. A successful embedding response does not establish retrieval quality.

## Step 3 · Activation gate

Activation is a state transition with conditions: expected model, numeric finite vectors, completed ingestion, scope checks and evaluation evidence. NaN is a floating-point value but has no valid distance ordering; booleans should not count as coordinates. For the cosine-distance index used here, a zero vector has no direction and is also rejected. Validate these before index activation, and preserve v1 when v2 fails.

### embedding_adapter.py

```python
"""Explicit opt-in local embedding adapter; install httpx and an embedding model.
Set LOCAL_EMBEDDING_MODEL and EXPECTED_EMBEDDING_DIMENSIONS after selecting and
inspecting your model. Importing performs no request. Never mix model indexes.
"""
import asyncio,math,os
import httpx
async def embed(texts,model,dimensions,endpoint='http://127.0.0.1:11434',transport=None):
    if not 1<=len(texts)<=32 or any(not isinstance(t,str) or not t.strip() or len(t)>20000 for t in texts):
        raise ValueError('1–32 nonempty bounded text chunks required')
    if not model or type(dimensions) is not int or dimensions<1:raise ValueError('model/index contract required')
    async with asyncio.timeout(30):
        async with httpx.AsyncClient(timeout=20,transport=transport) as client:
            response=await client.post(endpoint.rstrip('/')+'/api/embed',json={'model':model,'input':texts,'truncate':False})
            response.raise_for_status();data=response.json()
    vectors=data.get('embeddings')
    if data.get('model')!=model or not isinstance(vectors,list) or len(vectors)!=len(texts):raise ValueError('model or batch mismatch')
    for vector in vectors:
        if not isinstance(vector,list) or len(vector)!=dimensions:raise ValueError('embedding dimension mismatch')
        if not all(type(v) in (int,float) and math.isfinite(v) for v in vector):raise ValueError('non-finite embedding')
        if not any(v!=0 for v in vector):raise ValueError('zero vector has no cosine direction')
    # Preserve ordering: vectors[i] belongs to texts[i]. Count is real provider usage if supplied.
    return {'model':model,'dimensions':dimensions,'vectors':vectors,'input_tokens':data.get('prompt_eval_count')}
async def main():
    result=await embed(['Unopened items: 30 days. Personalized items excluded.','Shipping takes five days.'],
       os.environ['LOCAL_EMBEDDING_MODEL'],int(os.environ['EXPECTED_EMBEDDING_DIMENSIONS']))
    print({'model':result['model'],'dimensions':result['dimensions'],'rows':len(result['vectors']),'input_tokens':result['input_tokens']})
if __name__=='__main__':asyncio.run(main())
```
