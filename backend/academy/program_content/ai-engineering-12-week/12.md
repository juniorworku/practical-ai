## Reason through the decision

Map against the original submitted list; reject invalid/duplicate indexes and preserve a bounded no-rerank fallback.

A reranker scores only the candidates it receives. Map the provider’s original candidate index back to your immutable chunk ID, not to a reordered list. ## Vocabulary used in this session

### Candidate ceiling

Maximum evidence set sent to a reranker within budget.

### Index mapping

Provider result positions mapped back to immutable candidate IDs.

### Fallback policy

An explicit measured behavior when reranking exceeds its budget.

## Learn each concept step by step

Read these three explanations before running the specimen. Each connects a definition to the decision it controls.

## Step 1 · Candidate ceiling

A candidate ceiling bounds how many texts are sent to the reranker. Reranking cannot recover missing evidence, so first evaluate candidate recall. Sending a larger set increases text processing, latency and possibly spend; the right ceiling depends on observed quality gain and a remaining request deadline.

## Step 2 · Index mapping

The provider returns positions into the exact candidate array it received. Position 1 in [c3,c1,c2] means c1. Sorting that array before mapping changes identity even if every index is in range. Save the immutable submitted list and reject negative, out-of-range or duplicate indexes before using the output.

## Step 3 · Fallback policy

A fallback policy defines what happens when reranking is unavailable or would consume the remaining deadline. Returning the authorized original ranking can be acceptable if it is labeled and evaluated; fabricating reranker scores is not. Decide the fallback before failure and retain the failure in cost/quality reports.

candidates=[{'id':'c3','text':'irrelevant'}, {'id':'c1','text':'unopened return policy'}, {'id':'c2','text':'shipping'}]

```python
"""Opt-in async external adapters. No call is made merely by importing this file.
Choose endpoints/models explicitly and run only with authorized synthetic data.
"""
import asyncio
import json
import os

async def ollama_stream(messages,endpoint='http://127.0.0.1:11434',model=None):
    import httpx
    model=model or os.environ['LOCAL_MODEL']
    payload={'model':model,'messages':messages,'stream':True}
    completed=False
    async with asyncio.timeout(60):
        async with httpx.AsyncClient(timeout=httpx.Timeout(30,connect=5)) as client:
            async with client.stream('POST',endpoint.rstrip('/')+'/api/chat',json=payload) as response:
                response.raise_for_status()
                async for line in response.aiter_lines():
                    if not line:continue
                    item=json.loads(line)
                    if 'error' in item:raise RuntimeError('local model error')
                    if item.get('message',{}).get('content'):
                        yield {'event':'draft_delta','text':item['message']['content']}
                    if item.get('done'):
                        completed=True
                        yield {'event':'draft_complete','input_tokens':item.get('prompt_eval_count'),
                               'output_tokens':item.get('eval_count'),'model':model}
    if not completed:raise RuntimeError('stream ended before completion; do not cache as a full answer')

async def cohere_rerank(query,candidates):
    import cohere
    if not query.strip() or not 1<=len(candidates)<=30:raise ValueError('query and 1–30 candidates required')
    client=cohere.AsyncClientV2(api_key=os.environ['COHERE_API_KEY'])
    async with asyncio.timeout(15):
        result=await client.rerank(model=os.environ['COHERE_RERANK_MODEL'],query=query,
                                  documents=[c['text'] for c in candidates],top_n=min(5,len(candidates)))
    ids=[]
    for row in result.results:
        if type(row.index) is not int or not 0<=row.index<len(candidates):raise ValueError('invalid rerank index')
        identifier=candidates[row.index]['id']
        if identifier in ids:raise ValueError('duplicate rerank result')
        ids.append(identifier)
    return ids

async def main():
    async for event in ollama_stream([{'role':'user','content':'Explain why a draft needs review in one sentence.'}]):
        print(json.dumps(event))
if __name__=='__main__':asyncio.run(main())
```
