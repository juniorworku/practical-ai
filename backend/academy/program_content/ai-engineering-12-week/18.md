## The case

A calendar draft becomes consequential when it creates an event or invitation. Human approval must be checked again at dispatch, including expiry and revoked roles. A hash detects changed bytes but is neither an identity system nor a remote idempotency guarantee.

## Vocabulary used in this session

### Payload approval

Authority bound to exact recipients, time, destination and revision.

### Revocation check

Authority verified again when execution begins.

### Expiry

A bound after which prior approval no longer authorizes the effect.

## Learn each concept step by step

Read these three explanations before running the specimen. Each connects a definition to the decision it controls.

## Step 1 · Payload approval

Approval authorizes an exact effect payload, not a vague task name. Include calendar/destination, start/end with timezone, recipients and revision. Canonical serialization ensures stable field ordering before hashing. Changing a time or attendee after review must change the fingerprint and invalidate approval.

## Step 2 · Revocation check

Revocation is checked at execution time: a reviewer who had authority yesterday may have lost it today. A matching hash only proves payload equality; load the approval and current role from trusted application state. Do not accept a model-generated approval dictionary as the reviewer’s actual decision.

## Step 3 · Expiry

Expiry uses a precise boundary: now < expires permits, now >= expires denies. Check time interval validity before presenting a proposal; naive times without offsets are ambiguous. Normalize equivalent instants consistently for comparison, and require end after start. Idempotency and remote reconciliation are additional requirements taught separately.

## Predict before execution

Save this entire block as example.py in an empty directory. Run `python3 -I example.py` with assertions enabled. It uses only the Python standard library, includes its synthetic data and performs no provider calls. Explain each assertion before running.

```python
import hashlib,json
payload={'owner':'acme','destination':'calendar:team','start':'2026-11-03T10:00:00+03:00','attendees':['synthetic@example.test'],'revision':2}
def fingerprint(value):return hashlib.sha256(json.dumps(value,sort_keys=True).encode()).hexdigest()
approved={'digest':fingerprint(payload),'expires_at':100,'actor':'reviewer'}
def permitted(current,now,actor_active):
    return now<approved['expires_at'] and actor_active and fingerprint(current)==approved['digest']
assert permitted(payload,99,True)
assert not permitted(dict(payload,start='2026-11-03T11:00:00+03:00'),99,True)
assert not permitted(payload,100,True) and not permitted(payload,99,False)
print('approval binds exact time, recipients, destination and active reviewer authority')
```
