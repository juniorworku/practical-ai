## Learn each concept step by step

Read these three explanations before running the specimen. Each connects a definition to the decision it controls.

## Step 1 · Resident model memory

Resident memory includes weights and serving runtime before user context grows. Quantization changes the model artifact and memory footprint but can also change answer quality. Record model/license/revision, quantization, tokenizer, runtime and hardware so another operator can reproduce a comparison.

## Step 2 · KV cache

KV cache is attention state accumulated for input/output context during inference. More tokens and simultaneous requests generally require more memory, but the actual layout depends on model architecture, runtime, batching and cache management. Reserve runtime/headroom before estimating request slots; measured memory can differ from a worksheet.

## Step 3 · Artifact-specific evaluation

Artifact-specific evaluation compares the exact deployed model/runtime on identical labeled tasks. Ollama local streaming and a vLLM serving endpoint have different operational contracts even if a chat interface looks similar. Measure cold load, token lengths, throughput, p95, errors and quality. Fewer billed API calls do not make local GPU power/hardware/operations free.

### provider_adapters.py

```python
"""Opt-in async external adapters. No call is made merely by importing this file.
Choose endpoints/models explicitly and run only with authorized synthetic data.
"""
import asyncio
import json
import os

async def ollama_stream(messages,endpoint='http://127.0.0.1:11434',model=None):
    import httpx
    model=model or os.environ['LOCAL_MODEL']
    payload={'model':model,'messages':messages,'stream':True}
    completed=False
    async with asyncio.timeout(60):
        async with httpx.AsyncClient(timeout=httpx.Timeout(30,connect=5)) as client:
            async with client.stream('POST',endpoint.rstrip('/')+'/api/chat',json=payload) as response:
                response.raise_for_status()
                async for line in response.aiter_lines():
                    if not line:continue
                    item=json.loads(line)
                    if 'error' in item:raise RuntimeError('local model error')
                    if item.get('message',{}).get('content'):
                        yield {'event':'draft_delta','text':item['message']['content']}
                    if item.get('done'):
                        completed=True
                        yield {'event':'draft_complete','input_tokens':item.get('prompt_eval_count'),
                               'output_tokens':item.get('eval_count'),'model':model}
    if not completed:raise RuntimeError('stream ended before completion; do not cache as a full answer')

async def cohere_rerank(query,candidates):
    import cohere
    if not query.strip() or not 1<=len(candidates)<=30:raise ValueError('query and 1–30 candidates required')
    client=cohere.AsyncClientV2(api_key=os.environ['COHERE_API_KEY'])
    async with asyncio.timeout(15):
        result=await client.rerank(model=os.environ['COHERE_RERANK_MODEL'],query=query,
                                  documents=[c['text'] for c in candidates],top_n=min(5,len(candidates)))
    ids=[]
    for row in result.results:
        if type(row.index) is not int or not 0<=row.index<len(candidates):raise ValueError('invalid rerank index')
        identifier=candidates[row.index]['id']
        if identifier in ids:raise ValueError('duplicate rerank result')
        ids.append(identifier)
    return ids

async def main():
    async for event in ollama_stream([{'role':'user','content':'Explain why a draft needs review in one sentence.'}]):
        print(json.dumps(event))
if __name__=='__main__':asyncio.run(main())
```

## Apply the three pillars to A multi-user AI service deployed from containers

### Latency vs. Cost vs. Quality

Load-test offered vs. completed work, p95 and cost per accepted result at stated concurrency. Autoscaling settings are hypotheses until observed against downstream/GPU limits.

### Deterministic Evaluation

Test readiness against the actual database, restart/readback, isolated restore, denied owner access, overload rejection and a dependency outage on the deployed revision.

### Context Management

Budget resident model memory/KV cache and per-request context separately. Keep tenant/revision-aware application caches; never assume a process-local cache is shared across replicas.

## Failure and deployment work

Separate request concurrency, worker capacity and model/GPU capacity. Add admission control, shared quotas, bounded queues, maximum instances and a documented fallback/stop budget.

## Evaluation precision

Automate repeatable checks with fixed inputs and versioned expectations. Model judges, faithfulness scores and semantic reviews can be stochastic; record judge/configuration versions and disagreement rather than calling them deterministic truth.
