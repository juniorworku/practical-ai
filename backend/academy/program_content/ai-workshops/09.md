A benchmark is only meaningful when candidates receive comparable inputs, settings, and measurement rules. Define the dataset and scoring before running it. Record environment and version information. A tiny benchmark is useful for a local decision, but it does not establish universal superiority.

## Worked implementation: Run a small benchmark and write a decision memo

## Predict before running

Read the assertions and predict the output and rejected cases. Save the **entire** following block as `example.py` in a new scratch folder. Use Python 3.12; every import and synthetic fixture required for this example is included. Run `python3 -I example.py`. Assertions must be enabled; do not use `-O`. No model, network, database service or third-party package is required. SQLite examples create a temporary database and clean it up.

```python
fixtures={'d1':'café','d2':'two lines\nremain','d3':''}
def parser_a(text): return text
def parser_b(text):
    if not text: raise ValueError('empty unsupported')
    return text.replace('é','e')
results={}
for name, parser in [('A',parser_a),('B',parser_b)]:
    rows=[]
    for identifier,text in fixtures.items():
        try:
            output=parser(text)
            rows.append({'id':identifier,'ran':True,'exact':output==text})
        except ValueError:
            rows.append({'id':identifier,'ran':False,'exact':False})
    results[name]=rows
assert sum(r['exact'] for r in results['A'])==3
assert sum(r['exact'] for r in results['B'])==1
assert len(results['B'])==3
print({name:{'exact':sum(r['exact'] for r in rows),'total':len(rows)} for name,rows in results.items()})
```

## Expected observation

```text
{'A': {'exact': 3, 'total': 3}, 'B': {'exact': 1, 'total': 3}}
```

## Walk through the mechanism and its limits

These are toy parser functions, not benchmarks of named products. Both see identical inputs and exact-preservation scoring. B changes the accented character and fails empty input; its failed run stays in the denominator. Exact equality is useful for this preservation criterion, but would be wrong if approved normalization were intended. Define that choice before running.
