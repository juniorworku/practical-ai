## Why this decision matters

Classification automates a decision boundary. Define categories by the downstream action they enable, not merely by similar wording. A category is useful when its definition and examples help two people agree on the right handling. Include an uncertainty or review route when input does not establish a safe choice.

This project routes fictional support messages without sending replies or changing customer records. Urgency and topic are separate fields. A complaint about a delayed shipment may be a shipping topic and a normal priority; an account compromise may require an urgent human response regardless of tone. Avoid using sentiment as a substitute for operational severity.

## Vocabulary used in this session

### Taxonomy

Explicit categories defined by meaningful downstream handling.

### Multi-intent input

A message contains more than one relevant task or topic.

### Urgency

Operational severity assessed separately from topic or writing tone.

## Worked implementation: Design a taxonomy with an uncertainty route

Use Python 3.12; every import and synthetic fixture required for this example is included. Run `python3 -I example.py`. Assertions must be enabled; do not use `-O`.
```python
def classify(tags):
    # tags are manually annotated features, not a language-understanding system.
    topics=set(tags) & {'billing','shipping','account','product','other'}
    urgency='urgent' if 'compromise' in tags else 'normal'
    route=next(iter(topics)) if len(topics)==1 else 'review'
    return {'topics':sorted(topics),'urgency':urgency,'suggested_queue':route}
assert classify({'billing','account'})['suggested_queue']=='review'
assert classify({'account','compromise','polite'})['urgency']=='urgent'
assert classify(set())['suggested_queue']=='review'
print(classify({'billing','account','polite'}))
```

## Expected observation


## Walk through the mechanism and its limits

The input is an annotated feature set so the handling policy can be evaluated before NLP. Topic answers what kind of work; urgency answers its consequence and time sensitivity. Multiple material topics route to review instead of arbitrarily discarding one. A keyword detector added later will have its own errors and cannot inherit the correctness of these manually supplied tags.
