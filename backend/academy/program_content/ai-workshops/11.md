## Why this decision matters

A confusion matrix shows which categories are being mistaken for which others. Overall accuracy can hide a dangerous pattern when one category is rare. Establish a deterministic baseline first, then compare a model-based or hybrid classifier against the same labeled messages.

Fallback behavior is part of the classifier. Unknown outputs should not become a default operational action. A valid category string still needs permission checks before any write occurs. Keep automatic actions disabled in this project; the result is a suggested queue and explanation using observable features or evidence, followed by human review.

## Vocabulary used in this session

### Confusion matrix

Counts showing which expected categories were predicted as which other categories.

### Per-class recall

The share of true examples of a category correctly identified.

### Fallback route

An explicit review behavior for uncertainty, invalid labels or unavailable classifiers.

## Worked implementation: Routing rules, confusion matrices, and fallback

## Predict before running

Use Python 3.12; every import and synthetic fixture required for this example is included. Run `python3 -I example.py`. Assertions must be enabled; do not use `-O`. No model, network, database service or third-party package is required. SQLite examples create a temporary database and clean it up.

```python
labels=['billing','technical','review']
expected=['billing','billing','technical','technical']
predicted=['billing','technical','technical','urgent-refund-approved']
predicted=[p if p in labels else 'review' for p in predicted]
matrix={a:{b:0 for b in labels} for a in labels}
for gold,pred in zip(expected,predicted): matrix[gold][pred]+=1
metrics={}
for label in labels:
    tp=matrix[label][label]
    actual=sum(matrix[label].values())
    called=sum(matrix[row][label] for row in labels)
    metrics[label]={'recall':tp/actual if actual else None,'precision':tp/called if called else None,
                    'actual':actual,'predicted':called}
assert metrics['billing']['recall']==.5
assert metrics['technical']['precision']==.5
assert metrics['review']['recall'] is None
print({'matrix_rows_expected':matrix,'metrics':metrics})
```

## Walk through the mechanism and its limits

Rows are expected classes; columns are predicted classes. Billing recall is one correct billing prediction out of two billing inputs. Technical precision is one correct technical prediction out of two technical predictions. No expected review cases means review recall is undefined, represented by None rather than a misleading perfect score. The unknown model label falls back to review and cannot authorize a refund.
