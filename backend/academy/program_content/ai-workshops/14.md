## Why this decision matters

A critique loop needs criteria and a stopping rule. Otherwise it produces endless stylistic changes that do not improve usefulness. Separate factual review from clarity, accessibility, and tone. Use a maximum number of revisions and require a human to resolve factual disputes.

Compare drafts against the same rubric rather than asking a model whether it likes its own output. An automated reviewer can suggest problems, but it cannot certify facts absent from evidence. Preserve the initial draft, review notes, and revision so you can explain the effect of a change.

## Vocabulary used in this session

### Review rubric

Named criteria used consistently to assess draft quality.

### Factual review

Checking assertions against available evidence independently of style.

### Stopping rule

A defined point at which a revision loop ends or requires a human decision.

## Worked implementation: Draft, critique, and revise with a rubric

```python
# Explicit sentence IDs let a reviewer reject a specific unsupported assertion.
initial=['Choose your draft.','Guaranteed jobs.','Export CSV.']
allowed={'Choose your draft.','Review its source facts.','Export CSV.'}
required={'Choose your draft.','Review its source facts.','Export CSV.'}
def rubric(draft):
    return {'unsupported':[s for s in draft if s not in allowed],
            'missing':sorted(required-set(draft))}
def revise(draft):
    retained=[s for s in draft if s in allowed]
    if 'Review its source facts.' not in retained:
        retained.insert(1,'Review its source facts.')
    return retained
versions=[initial]
for _ in range(2):
    findings=rubric(versions[-1])
    if not any(findings.values()): break
    versions.append(revise(versions[-1]))
assert len(versions)==2 and rubric(versions[-1])=={'unsupported':[],'missing':[]}
assert versions[0]==initial
print({'before':rubric(initial),'after':rubric(versions[-1]),'revisions':len(versions)-1})
```

## Expected observation

```text
{'before': {'unsupported': ['Guaranteed jobs.'], 'missing': ['Review its source facts.']}, 'after': {'unsupported': [], 'missing': []}, 'revisions': 1}
```

## Walk through the mechanism and its limits

This is a closed-set, deterministic rubric over known sentences, not a general factuality detector. It finds two different defects: an unsupported promise and a missing review step. One revision removes the first and restores the second while preserving the original for comparison. The loop has a bound and a success condition; a real reviewer still checks readability and task completion.
