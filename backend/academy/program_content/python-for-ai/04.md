## Learn each concept step by step

## A deadline is a lifetime boundary
The provider fixture sleeps for a minute; the caller allows only 20 milliseconds. asyncio.timeout cancels the enclosed task when its deadline expires. Outside the context this becomes TimeoutError. The provider's finally sets cleaned, so the test verifies cleanup rather than merely measuring that an exception appeared.

## Run and inspect the control flow
1. Enter the timeout context before awaiting the dependency.
2. The provider suspends, so the loop can run its deadline callback.
3. Cancellation reaches the provider at the await.
4. Its finally runs and marks cleanup complete.
5. The caller receives TimeoutError outside the context and verifies that no success response escaped.

## Preserve cancellation
Do not catch BaseException or CancelledError and return a plausible answer. In a task group, suppressing cancellation can leave other work waiting indefinitely. Cleanup should be short and should not perform an unbounded network request. If cleanup itself needs I/O, give it a separate small budget and record an unresolved resource if it fails.

## Blocking work has different semantics
asyncio.to_thread moves a blocking call off the event loop, but cancelling the awaiting coroutine does not stop the underlying thread. A CPU-bound pure Python loop may need a process worker with admission control. An HTTP client should support native async cancellation plus connect/read/write timeouts. The capstone uses async HTTP for model requests and small off-loop SQLite operations; cancellation does not roll back an already committed cache write.

## Test time deterministically where possible
This fixture asserts cleanup and error type, not an exact 20ms observed latency. Shared machines can schedule later. Use virtual clocks or injected timers for a large timing matrix, and separately measure real deadline overshoot under load.

```python
import asyncio

async def main():
    cleaned = asyncio.Event()
    async def provider():
        try:
            await asyncio.sleep(60)
            return 'unreachable'
        finally:
            cleaned.set()
    try:
        async with asyncio.timeout(0.02):
            await provider()
    except TimeoutError:
        assert cleaned.is_set()
        print('Deadline propagated cancellation and ran cleanup')
    else:
        raise AssertionError('deadline not enforced')
    # Cancellation is cooperative. A CPU loop with no awaits blocks this deadline.
asyncio.run(main())
```

## Separate coroutine cancellation from thread lifetime

## Separate coroutine cancellation from thread lifetime

Cancellation is cooperative and applies to the coroutine you own. A running function in a thread is not forcibly terminated when its asyncio waiter is cancelled. The studio makes this visible with separate entered, release and finished threading events.

1. Start a blocking function with asyncio.to_thread and wait until it has actually entered. The threading.Event.wait calls also run off-loop through to_thread; calling those blocking waits directly in the coroutine would stall its event loop.
2. Cancel the awaiting task and observe CancelledError.
3. Check that the underlying function has not finished. This is the precise counterexample to “cancel stops all work.”
4. Release its independent stop event in finally and wait for its completion with a finite bound.
5. Keep every blocking call’s own timeout. asyncio.run waits for executor cleanup, so abandoning a thread can keep shutdown waiting.

The primary variation wraps both attempts in one timeout and separately tests explicit parent cancellation. Neither test asserts an exact elapsed millisecond value. The capstone includes storage and queue waiting in its overall deadlines, but an already-committed thread write is not rolled back by cancelling its waiter.

## Complete advanced studio

Save this entire block as studio.py and run `python -I studio.py` with Python 3.12. It is a standalone standard-library exercise; it does not import another lesson. Predict the assertion outcomes before running.

```python
import asyncio
import threading

async def main():
    entered=threading.Event();release=threading.Event();finished=threading.Event()
    def blocking_work():
        entered.set()
        try:release.wait(timeout=3)
        finally:finished.set()
    job=asyncio.create_task(asyncio.to_thread(blocking_work))
    try:
        assert await asyncio.to_thread(entered.wait,2)
        job.cancel()
        try:await job
        except asyncio.CancelledError:pass
        else:raise AssertionError('cancellation swallowed')
        assert not finished.is_set(), 'a cancelled await does not terminate a running thread'
    finally:
        release.set()
        assert await asyncio.to_thread(finished.wait,2)
    print('Cancelled coroutine; underlying thread required its own release/timeout')
asyncio.run(main())
```
