import hashlib
import json

def key(owner, model, source_version, prompt_version, query):
    fields = [owner, model, source_version, prompt_version, query]
    return hashlib.sha256(json.dumps(fields, ensure_ascii=False).encode()).hexdigest()

cache = {}

## Coalesce duplicate work without crossing owners or lifetimes

## Coalesce duplicate work without crossing owners or lifetimes

A cold durable cache can receive two identical requests simultaneously. A plain get→compute→put sequence can compute both. The studio adds a per-event-loop in-flight registry; it does not replace durable storage or a distributed lock.

1. The key is already scoped by owner and revisions. Look up a strongly retained task before starting another computation.
2. Register one created task and attach a completion callback that removes only that exact task identity.
3. Await it through shield so cancelling one waiter does not cancel work still needed by another.
4. Retrieve abandoned exceptions and own an explicit close method that cancels/awaits outstanding tasks.
5. Cancel the first waiter, release the shared computation and prove the second receives the answer after exactly one call.

Shield is not permission to leak tasks. The service owns the underlying task until completion or close. Its completion callback retrieves an abandoned failure so it is observed, but awaiting callers still receive that failure. close snapshots the tasks, cancels them and awaits gather(return_exceptions=True) to finish every cleanup rather than leaving on the first error. The threaded capstone deliberately does not share this async registry across request-loop lifetimes; its durable owner/revision cache remains valid even if simultaneous cold requests duplicate safe read work.

## Complete advanced studio

Save this entire block as studio.py and run `python -I studio.py` with Python 3.12. It is a standalone standard-library exercise; it does not import another lesson. Predict the assertion outcomes before running.

```python
import asyncio

class SingleFlight:
    def __init__(self):self.pending={}
    async def get(self,key,compute):
        task=self.pending.get(key)
        if task is None:
            task=asyncio.create_task(compute())
            self.pending[key]=task
            def done(completed):
                if self.pending.get(key) is completed:self.pending.pop(key,None)
                if not completed.cancelled():completed.exception()  # Retrieve abandoned failures.
            task.add_done_callback(done)
        # Cancelling one waiter must not cancel the result needed by another.
        return await asyncio.shield(task)
    async def close(self):
        tasks=list(self.pending.values())
        for task in tasks:task.cancel()
        await asyncio.gather(*tasks,return_exceptions=True)
        self.pending.clear()

async def main():
    service=SingleFlight();entered=asyncio.Event();release=asyncio.Event();calls=0
    async def compute():
        nonlocal calls
        calls+=1;entered.set();await release.wait();return 'answer'
    first=asyncio.create_task(service.get(('owner-a','revision-v1'),compute))
    await entered.wait()
    second=asyncio.create_task(service.get(('owner-a','revision-v1'),compute))
    try:
        await asyncio.sleep(0);first.cancel()
        try:await first
        except asyncio.CancelledError:pass
        release.set()
        assert await second=='answer' and calls==1
    finally:await service.close()
    assert not service.pending
    print('One computation, cancellation-isolated waiters and explicit service cleanup')
asyncio.run(main())
# This registry coalesces in-flight work only. Durable caching and distributed
# coordination are separate layers; keys must already include owner/revisions.
```
