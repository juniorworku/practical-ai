# Student teaching review: Bootcamp, Workshops and Freelancing

Date: 2026-10-20. Scope: all 24 AI Agent Bootcamp, 18 AI Workshops and 18 Freelancing Masterclass lessons. These remain independent programs with their own source material, examples, practice and progress. GenAI Accelerator and AI Engineering remain separate.

## Teaching and practice

Each lesson now explains its three concepts before implementation or exercises. The explanations teach mechanism, concrete application and a boundary. A three-step causal walkthrough then follows the actual baseline or completed client specimen. Students attempt a bounded change before extending it into the larger project.

The 42 technical lessons include complete executable practice references. The 18 business lessons include completed changed-case decisions, memos, tables or acceptance records; five also include self-contained Python calculations, pilot persistence, recovery or package checks. Every lesson provides three progressively revealed hints, failure diagnosis, reflection self-review guidance and feedback tailored to the selected quiz option. Wrong-answer feedback links back to the teaching chapter.

Original project work and its acceptance requirements are retained as an explicit next integration stage. A small exercise no longer implies that the student has already built a complete production system. Module release gates still require latency/cost/quality evidence, repeatable evaluation, context/cache boundaries and deployment/failure observations. Assumed, simulated, observed and untested results remain distinct.

## Concrete repairs

- Bootcamp retrieval now defines passage recall separately from case hit rate and demonstrates a two-gold/one-retrieved case.
- The regression baseline executes actual request inputs through a candidate with deliberate detectable defects. Expected labels stay outside the request. An improved aggregate can still hide a missing-evidence regression.
- Source ingestion rejects changed content under a reused revision identity.
- The bounded state machine rejects answering before the required retrieval transition.
- Approval checks include exact payload, owner, reviewer identity, expiry and current authority; a local unique claim is explicitly distinct from remote delivery guarantees.
- The structured-output JSON and citation exercise now match the exact-field validator, so the intended unknown-citation failure is reached rather than an unrelated missing-status error.
- The capstone distinguishes a policy-supported negative answer from abstention for missing applicable evidence.
- Workshops add complete practice for unknown/conflicting extraction values, decimal normalization, acceptance versus field accuracy, retractions and stale confirmation, summary dependency loss, research claim overreach, per-class routing errors, content-bound approval and durable readback.
- Freelancing adds worked stop/rescope decisions, discovery evidence correction, benefit break-even, capacity and usage calculations, acceptance additions, change-impact records, honest evaluation memos, reviewer-delay plans, ownership/recovery rehearsal and evidence-based handover. The effort lesson no longer points to an unrelated benefit calculation as if it were present there.
